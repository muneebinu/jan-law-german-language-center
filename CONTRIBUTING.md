# Contributing

Thank you for taking an interest in this project.

This repository powers the public website for Jan Law German Language Center. Keep changes focused, accessible, responsive and easy to maintain.

## Development setup

- HTML, CSS and browser JavaScript are served as static files.
- Node.js 18 or newer is only needed to run the repository checks.
- No frontend framework, package installation or build process is required.

## Before submitting a change

1. Keep page content in `index.html`, styling in `assets/css/site.css`, and browser interactions in `assets/js/site.js`.
2. Use semantic HTML and preserve keyboard navigation, visible focus and reduced-motion support.
3. Use relative paths for repository assets so GitHub Pages can serve them correctly.
4. Do not add unverified fees, phone numbers, opening hours, testimonials, qualifications, accreditations, exam-centre claims or visa and employment guarantees.
5. Avoid adding dependencies unless there is a clear technical reason.
6. Run `npm run check` and review the site at mobile and desktop widths.

## Reporting an issue

Include the affected page or section, steps to reproduce, expected behaviour and actual behaviour. Screenshots are useful for visual issues. Never include private student or applicant information.
